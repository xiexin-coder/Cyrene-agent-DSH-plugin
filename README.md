# 昔涟 DSH 插件 · Cyrene-agent-DSH-plugin

> 一个能让 [DSH](https://github.com/) 以 **昔涟** 的人设与你对话的插件，附带专属定制的昔涟主题美化界面 🌸

![License](https://img.shields.io/badge/License-Apache--2.0-blue.svg)
![Version](https://img.shields.io/badge/version-v1.0.0-pink.svg)

---

## ✨ 特性

- 💬 **昔涟人设对话**：按昔涟的语气、性格与记忆逻辑回应，代入感拉满
- 🎨 **专属主题美化**：定制配色、字体与界面细节，贴合昔涟的视觉氛围
- 🧩 **即插即用**：放入 DSH 插件目录即可启用，无需改动主程序

## 📦 安装

1. 下载 **[Releases](https://github.com/xiexin-coder/Cyrene-agent-DSH-plugin/releases)** 中的 `Cyrene-agent-DSH-plugin-v1.0.0.zip` 并解压
2. 将文件夹放入 DSH 的插件目录（例如 `DSH/plugins/`）
3. 重启或刷新 DSH，在插件列表中启用「昔涟」
4. 新建对话，开始聊天～

> 如需从源码运行：把本仓库克隆到插件目录，按下方「开发」一节准备即可。

## 🚀 快速开始

启动 DSH → 选择「昔涟」角色 → 输入第一句话，昔涟会主动接住你。
